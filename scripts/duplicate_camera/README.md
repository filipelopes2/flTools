# Duplicate Camera

## Overview

The tool creates another camera, copies all parameters from the original camera, parents to the original camera and bake all animations.

## Use cases

Very useful when a camera was animated with a rig, and it has to be exported to another software or used in another way.

## How to use it

- Select the camera to be duplicated and run the tool
