# Yeti Tools

## Overview

Some functions to help create initial graph nodes for hair and fur creation. 

## Known issues

Nodes will be stacked after created. To solve that, open the Graph Editor and go to `Edit > Auto-Layout`

## How to use it

### Initial Graph

1. select the objects and run the tool


2. the tool will create:
    - one `Texture Reference` for each object
    - a `yeti` node
    - initial nodes on the graph

### Initial Graph - With Groom

1. select the objects and run the tool


2. the tool will create:
    - one `Texture Reference` for each object
    - a `yeti` node
    - a `groom` node
    - initial nodes on the graph
