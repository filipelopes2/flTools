# Random Color Shaders

## Overview

Creates an aiStandardSurface shader with a random color for each selected object.

The names of the created materials and shading groups are based on the object's name.

## Use cases

- scene presentation
- lookdev creation or debugging

## How to use it

- select the objects and run the tool
