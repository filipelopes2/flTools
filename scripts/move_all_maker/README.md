# Move All Maker

## Overview

Creates three controls parented to a joint and connects them to the selected objects.

Also creates display layers to help organize the scene.

## Use cases

Good to use as a master control for characters or props.

## How to use it

1. Select all objects that will be affected


2. Choose the parent type
 

3. Click in `create move all`
