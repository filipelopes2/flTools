# Archive Scenes

## Overview

Creates a zip file with all resources for each Maya scene selected ( file textures, image planes, caches, etc... ).

## Use cases

Pack scenes to send to a vendor/client/freelancer.

## Known issues

A window might open asking about unsaved changes. Just cancel it. I still can't figure out how to not show this.

## How to use it

1. Select the folder where the files are located ( it can be the project root folder )


2. Select a folder to save all zip files


3. Select the files you want to archive


4. Click the `archive` button
