# Camera Keyframer

## Overview

Creates keyframes on the selected camera, and it's respective aim ( if it exists ).

Keyframes created on: translation ( XYZ ), rotation ( XYZ ) and focal length.

## Use cases

Useful when animating a camera looking through it and don't want to select the camera to set frames.

## Known issues

If the camera has an aim, it must the named `[camera name]_aim` ( e.g. camera1_aim ).

## How to use it

1. Select the camera and click `select`


2. Click `set key ` to set keyframes on the camera, and it's respective aim ( if it exists ). You don't have to keep the camera selected
 

3. Use `focal length curve` to change the curve on focal length to "stepnext"
